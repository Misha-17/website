## Homepage evidence explorer

- **Control question:** supplied Readable but Not Writable draft, pp. 1, 6, 8–9. Four models and fourteen personas. Persona-expression scores: baseline 1.54/5, activation steering 1.63/5, prompt steering 3.91/5, combined 3.95/5. Activation vs baseline p = 0.21; combination vs prompt p = 0.43. The description scopes the result to the tested additive interventions and distinguishes decoding from successful control.
- **Felt-understanding question:** supplied master's thesis, pp. 66–70. 200 participants, 97 baseline and 103 personalized. No improvement detected in measured felt-understanding outcomes; all reported condition effects d < 0.25. The claim is scoped to this experiment and Big Five prompt personalization.
- **Causal-signal question:** supplied master's thesis, p. 89. 798 anticommonsense CLadder items, Qwen2.5-7B-Instruct. Cross-validated probe accuracy 70.4%; generated output accuracy 55.5%; difference 14.9 percentage points. This is recoverable information evidence, not a demonstration of successful causal control.

The displayed experimental numbers are reported observations, not results of a live simulation or an analysis rerun during website creation.
